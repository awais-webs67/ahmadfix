Findings

Forced Arabic Client-Side Redirect Bounces Human Visitors Off /en/* Deep Links High

Because Admin 'Default website language' is set to Arabic (mode = 'ar'), includes/header.php redirects first-time human visitors landing on /en/* URLs (e.g., from an English Google SERP result) to /ar/*.

Recommendation: Set Default website language to 'Automatic' in /admin, or update includes/header.php so forced language only applies on root entry and never overrides explicit /en/* or /ar/* deep links.

Add Bing Webmaster Verification Token (msvalidate.01) Low

Google Search Console verification is active, while msvalidate.01 is still empty ( affects Bing & Microsoft Copilot reporting).

Recommendation: Import your verified GSC property into Bing Webmaster Tools or paste msvalidate.01 in Admin -> Settings -> Google & Social.
